# recallio_core

The shared Recallio (Spaced Loop) engine: FSRS scheduling with the exam cap, the daily planner, the sitting builder, bonus sittings, cram mode, the weekly report, and the Daily Feed UI. Course apps (for example `apps/energy_app`) depend on it by path.

See `docs/recallio/` at the repo root.

```sh
flutter test   # engine unit tests
```
